ROOT CAUSE CONFIRMED
The old V187 database functions allowed only six routes:
attendance, exams, timetable, homework, events, notices.
Any newer route selected in the Admin UI was silently changed to NULL in SQL.
Therefore the task reached Teacher, but the ERP link disappeared.

V266 FIX
- Database no longer silently NULLs a selected route.
- Valid current operational routes are preserved.
- Invalid/protected routes raise a visible error.
- Owner/security/financial-control routes are not offered.
- New ERP Work requires a Linked ERP Function.
- General Work is an explicit checkbox and requires Instructions.
- After Create/Edit, frontend re-reads the saved task and verifies module_route.
- Existing blank tasks show "Link Missing" / "Link Pending".
- Admin gets direct "Link Now" on broken tasks.
- Existing tasks/assignees are not deleted or auto-guessed.
