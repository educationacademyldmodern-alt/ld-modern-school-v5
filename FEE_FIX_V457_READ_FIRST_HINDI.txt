V450 — फीस तय करना / Save error सुधार

1. ZIP Extract करें। HTML/JS/CSS/assets को website की उसी जगह Replace करें; अन्य पुरानी files न हटाएँ। इस बार school-workspace-v336.js और school-workspace-v336.css भी हैं।
2. Supabase → SQL Editor में केवल SQL/05_FEE_PLAN_START_MONTH_V457.sql का पूरा code एक बार चलाएँ। पुराने 00–04 फिर नहीं। Website पर SQL upload नहीं करनी है।
3. परिणाम में start_month_guard और fee_rpc_patched दोनों true होने चाहिए। फिर ERP Refresh करें। यदि prerequisite/body error मिले तो script rollback करता है; constraint या पुराने records को manually न हटाएँ।

आसान फीस सेटअप:
Class चुनें → Monthly या Installment → शुरू/अंत की तारीख → राशि/किस्तें → विद्यार्थी चुनें → Preview → Save।
जनवरी–मार्च Monthly ₹1200 = मूल कुल ₹3600 प्रति विद्यार्थी।
एक Installment ₹1200 = केवल उसी तारीख पर मूल ₹1200।
अलग तय व्यक्तिगत योजना बदलनी न हो तो replace वाला tick न लगाएँ।
पुरानी billed फीस और receipts का हिसाब मौजूदा backend के अनुसार सुरक्षित रहता है।

यह नया SQL पुराने function की permission/idempotency बचाकर missing start month को ठीक करता है। नया polling/API loop नहीं है। हर वास्तविक Save फिर भी आवश्यक database काम करता है।
जाँच local PostgreSQL और browser mocks में हुई है; आपकी live database पर SQL हमने नहीं चलाई है।
