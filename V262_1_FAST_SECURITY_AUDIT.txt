CONFIRMED ROOT CAUSE OF V262 SLOWDOWN
V262 added a permanent MutationObserver over the whole document. On random Vercel preview URLs,
its callback called applyOriginTrust(), which rewrote the security status HTML. That DOM write
could trigger the same observer again, causing repeated work and slow/hanging behavior. V262 also
ran an auth wrapper retry every 250ms for up to 5 seconds.

V262.1 ROOT FIX
- V262 security MutationObserver removed completely.
- V262 auth retry setInterval removed completely.
- Preview-password auth guard installs once inside the existing Supabase init() only.
- Login security status paints once.
- Dynamic password protection uses one passive interaction path (focus delegation), not DOM scans.
- Restrictive CSP removed from vercel.json to avoid blocking legacy/dynamic ERP helpers.
- HSTS, nosniff, X-Frame-Options, Referrer-Policy and Permissions-Policy retained.
- Moderate cache header added for static assets to improve repeat-load speed.
- No SQL, table, RLS, fee, attendance, exam, student or central-data change.
