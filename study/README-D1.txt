SKY SIR TEACHER-FIRST D1
========================

WHY D1
- Login no longer blocks teaching.
- Main use is simple: Board or Competition -> select -> Start Class.
- Cloud/Supabase is optional backup/sync only.
- Competition tools open the material workspace directly.
- Mobile hides advanced batch/language/mode controls by default.

- Current affairs and changing facts remain source-gated.

HOW TO USE
1. Open website. No login required.
2. Tap Competitive Exams.
3. Select Exam -> Subject -> Chapter -> Topic -> Duration.
4. Tap START CLASS — COMPLETE MATERIAL.
5. Use Teach Now / Notes / Practice / PPTX / Print Kit.
6. Use Cloud Backup/Sync only if you want cross-device data.

UPLOAD
