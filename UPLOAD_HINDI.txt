पिछले संयुक्त सुधारों का विवरण:

Classes:
- Native checkbox और label पर एक click से चयन; बड़े hit targets और बिना text drag वाला label।
- चयन बदलते ही student/room count अपडेट; इस दौरान कोई roster/database request नहीं।
- उसी exam/session के roster को फिर Load करने पर चुनी हुई classes बरकरार। दूसरे exam/session पर नई selection।
- Canonical duplicate class labels हटे; All / Unselect और Nursery/LKG/UKG शामिल।
- पुराना hidden Room layout panel सच में hidden रहेगा; quick room setup इस्तेमाल होगा।

PDF / paper:
- PDF text को coordinates के अनुसार lines और पहचाने गए दो columns में पढ़ना। Printed logical page numbers मिलने पर booklet पढ़ने का क्रम सुधारना और exact duplicate copies हटाना।
- Import में हर प्रश्न को अलग section बनाने के बजाय मूल section/type के प्रश्न एक साथ।
- MCQ options printable अलग options; matching columns / source order सुरक्षित। बिना answer key वाले imported matching के सही उत्तर अपने-आप नहीं गढ़े जाते।
- मूल प्रति-प्रश्न अंक सुरक्षित; import पर smart auto-marks बंद। छपे total से अंतर हो तो review message।
- Single / Auto print selection बना रहता है; पुराने forced page count को imported paper में नहीं ढोता।
- Original source text और import से पहले backup / undo बने हैं।

SQL:
Seating / class / PDF सुधार के लिए कोई नया SQL नहीं। SQL/01_FEE_LOOKUP_INDEXES_SAFE.sql वही V427 का index-only SQL है। पहले चला चुके हैं तो फिर जरूरी नहीं। नहीं चलाया तो counter कम व्यस्त होने पर एक बार चलाएँ। Records और payment functions नहीं बदलता।
