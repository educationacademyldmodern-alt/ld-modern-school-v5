V431 — Shared exam paper structure: import, options, sections and central Preview / PDF / Print

ZIP की सभी root HTML/JS/CSS files तथा folders को उसी existing ERP root में upload/replace करें। paper-structure-v431.js, नया typing bridge और paper-print-v431.js साथ upload होना जरूरी है। बाकी पुरानी ERP files न हटाएँ। Browser hard refresh करें; paper फिर खोलकर नई PDF बनाएँ। यह existing ERP का update है, पूरा नया ERP नहीं।

पुराने V430/V429/V428/V427 सुधार साथ हैं: बिना decorative lines का paper, class selection, same-seat desk/attendance, fee fast search/save। V423 fonts/spacing files भी साथ हैं। कोई नया SQL नहीं है। साथ का SQL वही V427 का index-only SQL है; पहले चला चुके हैं तो फिर न चलाएँ।

क्या सुधरा:
- Letter / Hindi / Roman / numbered / pipe वाले स्पष्ट MCQ options एक संरचना में। Options a,b,c… के रूप में अलग छपेंगे।
- MCQ, fill blanks, True/False, matching, very short / short / long तथा custom question-type sections।
- मूल explicit sections और question order सुरक्षित; हर प्रश्न का अलग section नहीं। हर section में numbering 1 से और headings A,B,C…।
- स्रोत में sections न हों तो पहचाने type के अनुसार contiguous sections बनते हैं। अस्पष्ट short/long या खराब OCR से सही content invent नहीं किया जाता।
- Math के (a),(b) subparts को बिना आधार MCQ choices नहीं बनाया जाता। Matching के दोनों columns और source order सुरक्षित; अज्ञात answer key नहीं गढ़ी जाती।
- प्रति-प्रश्न मूल marks सुरक्षित; import पर अनचाहा auto redistribution नहीं। कुल/मूल total का अंतर review में दिखता है।
- Reviewer में प्रत्येक प्रश्न का type, section number, text, options/right match और marks बदल सकते हैं। Section number बदलने पर section क्रम में जाता है। अधूरा MCQ / खाली matching right / गलत marks लागू करने से पहले ठीक करने होंगे।
- Question-wise typing mode भी मुख्य sectioned paper engine से Preview/Print देता है। Font, line spacing, booklet और no-lines styles वही लागू हैं। मूल दोनों editing drafts सुरक्षित रहने वाला व्यवहार बरकरार है।

कैसे उपयोग करें:
Import → file चुनें → पहचाने प्रश्न/options/marks देखें। जिस प्रश्न में कमी हो उसका “प्रकार / सेक्शन / प्रश्न / विकल्प सुधारें” खोलें। MCQ options एक-एक line जैसे (a) पहला, (b) दूसरा भरें। Matching में right field भरें। फिर “जाँचे प्रश्न Editor में खोलें” → Preview → Print / Save PDF। केंद्रीय रिकॉर्ड के लिए ERP का Save draft / Send Admin इस्तेमाल करें।

जाँच:
24 pure structure cases; actual PDF.js से portrait / 4–1,2–3 booklet और बिना section वाली PDF; numeric/Roman options; math subparts; Hindi digits/marks; incomplete-MCQ gate और repair; section reassign; typing/section round-trip और central preview; final generated PDF में दो copies के सभी 8 options और no-toolbar/no-decorative-rules। Source code और cache links भी जाँचे गए।

सीमाएँ:
आपकी समस्या वाली मूल PDF उपलब्ध नहीं थी। Scanned/OCR और धुँधले/गलत encoded PDF में पहचाना text मूल से मिलाएँ; चित्र/जटिल formula स्वतः editable नहीं बनते। वास्तविक school DB save/send, production SQL और physical printer यहाँ नहीं चलाए गए।
