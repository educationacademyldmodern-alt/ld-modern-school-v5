Base: V271 Premium Admin Clean

CONFIRMED ROOT PROBLEM
Earlier Assigned Work could show the task and route, but only the outer Teacher route guard was bridged.
Many Admin modules then performed their own "Admin only" check or database RLS check, so Teacher could
see "Open Function" yet still fail to actually operate the linked function.

V272 ROOT FIX
1. Open Function validates the exact assignment + exact route on Supabase first.
2. It creates a short-lived exact-route delegated context only after server validation.
3. Existing Admin helper layers v14Admin/v90Admin and selected later helper checks accept that context
   ONLY while the exact linked route is opening/current.
4. profile.role is NEVER changed to Admin.
5. High-risk Admin controls are no longer offered in the delegation dropdown.
6. Old unsupported tasks remain visible but must be edited by Admin to a delegation-ready function.
7. Work Date added:
   - today = usable today
   - tomorrow = shown as Upcoming and cannot Start/Open today
   - tomorrow it becomes available automatically by date
8. Teacher status RPC also enforces Work Date server-side.
9. Program/Tour Register gets exact active-assignment RLS policies plus limited roster RPCs,
   so the delegated coordinator can actually manage the program without broad Student/Staff table access.
10. Master Gate Pass keeps its existing dedicated delegation security path.
