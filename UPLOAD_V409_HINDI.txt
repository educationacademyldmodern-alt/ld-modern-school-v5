PAPER IMPORT का रास्ता
Admin/Teacher → Question Paper Setup → नया या अपना saved paper खोलें → “पेपर सेटअप / Import” → “पेपर Import • Word / PDF / HTML” → file चुनें।
पढ़ने योग्य file से numbered questions अपने-आप review में तैयार होंगे। प्रश्न/विकल्प/अंक मिलाएँ → reviewed tick → “जाँचे प्रश्न इस पेपर में रखें” → ऊपर Save draft / Send। फिर उसी central Preview / Print-Save PDF का उपयोग करें।
Source में नंबर न हों तो “हर लाइन एक प्रश्न” चुनकर फिर प्रश्न तैयार करें। Unknown per-question marks को 1 माना जाता है और warning आती है। Source total marks अलग हों तो Submit/Preview से पहले अंक ठीक करें। Class/Subject/Session मूल teacher-selected setup से रहते हैं; source से assignment guessing नहीं की गई है।

SUPPORTED / LIMITS
• Word .docx: text, paragraphs, explicit breaks/tabs, ordinary automatic lists और options पढ़े जाते हैं। Header/footer images, styles-based lists, equations और complex tables का exact reconstruction नहीं है।
• PDF: readable text PDF, 10 MB तक / अधिकतम 50 pages / 200000 text characters। सही Unicode वाले हिन्दी PDF की जाँच की है। Scan/photo, broken font encoding, password-protected/unreadable PDFs editable paper में बिना OCR नहीं बदलते। Encoding खराब हो तो auto-apply blocked और OCR/DOCX लेने का संदेश है। OCR engine इस update में नहीं जोड़ा गया है।
• HTML/HTM: text/ordered lists/table text लिया जाता है; scripts/resources execute या upload नहीं होते। Original page का design/images/complex maths auto-convert नहीं होते।
• .doc: Word द्वारा HTML के रूप में saved .doc पढ़ता है। पुराने binary .doc को Word में Save As → .docx करें। सभी .doc formats का समर्थन होने का दावा नहीं है।
• TXT / ERP JSON / savedState वाले ERP HTML backups भी लिए जाते हैं।
कोई arbitrary paper 100% बिना review तैयार होने का दावा नहीं है। मूल file अपने पास रखें; options/marks/layout जाँचना जरूरी है।
