ADMIN INITIAL LOAD — LIGHTWEIGHT
The previous Academic Monitor could request school-wide:
- teaching_diary up to 15,000 rows
- copy checks up to 15,000 rows
- bell tests up to 15,000 rows
- timetable up to 10,000 rows
V267 removes that Admin initial-load pattern.

Now Admin initial open loads only:
1. Teacher Master list.
2. One read-only aggregate summary RPC (ldm_v267_teacher_academic_summary).

Only after one Teacher is selected:
- that Teacher's teaching_diary (max 2,500 in selected 7/30/90-day window)
- that Teacher's copy checks (max 2,500)
- that Teacher's bell tests (max 2,500)
- that Teacher's timetable (max 700)
- small syllabus_master session rows, filtered locally by assigned class aliases.
No student roster is loaded until Admin/Teacher explicitly clicks "Load Students / Pending List".
