CONFIRMED DEFECTS CORRECTED
1. Extensions accessed window.profile/user/sb/cls while the core declared global lexical variables. Added a live getter/setter bridge before extensions. Also exposes school branding and current exam read access.
2. Mobile #erp display:block!important overrode .hidden. Scoped the mobile rule and explicitly protected hidden portal containers.
3. Collapsed desktop content max-width still used expanded sidebar width. Unified the width variable for collapsed mode.
4. Two sibling selectors raced after asynchronous portal loads. Retained one selector, used record ID data attributes, scoped observation to direct portal-child replacement, rebuilt after rerender, and retained Back to My Children. Same names/missing admission numbers no longer serve as child identity. This is UI selection, not a replacement for database authorization of children or all shared service panels.
5. Password button selected hidden ERP header for parents. It now selects visible portal headers.
6. Password-profile write errors were ignored. Errors remain visible; a failed profile update no longer reports full success.
7. Parent sibling linking always forced password change even without changing a password. The API now sets the flag only when password changes.
8. Teacher assignment edits also forced password change, and short supplied passwords were silently ignored. Corrected both in API and retained root copy.
9. Session route restoration raced asynchronous openERP/admin verification. Restoration now awaits it and checks ERP visibility.
10. Parent action arguments now use JSON string serialization plus HTML escaping, preserving admission values containing quotes safely.
11. Bulk fee reminders had fixed 86mm height plus overflow:hidden, potentially clipping content. Changed to one A4-sized notice per printed page with natural content flow and no clipping rule. Actual printer/page-fit validation remains required, especially unusually long field values.
12. Existing profiles_update policy permits own-row updates without column restrictions. Added an additive trigger patch protecting role/status/student-link and other non-self-service fields. Existing policies are preserved. Requires live schema/permission verification before use; does not certify all other RLS rules or RPCs.
