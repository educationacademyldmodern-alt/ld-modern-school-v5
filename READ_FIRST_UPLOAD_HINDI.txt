क्या सुधरा
• Menu की desktop/mobile state एक जगह से चलती है; हर click पर nav फिर नहीं बनता।
  Desktop sidebar खुलने पर main content उसके बगल में आता है। पुराने shell helpers
  sidebar बंद करें तो नई state भी उसी समय sync होती है।
• Back/Home history बदलने से पहले pending Save/unsaved changes जाँचते हैं।
  Cancel करने पर attendance बदलाव और वही screen सुरक्षित रहते हैं। Back पर
  उपलब्ध पुरानी scroll position restore होती है। चालू Save की पुष्टि बाकी हो
  तो navigation रोकना जानबूझकर रखा गया है।
• नई route चुनने पर पुरानी route के पढ़ने वाले requests cancel होते हैं;
  जरूरी Save requests cancel नहीं होते। समान route requests साथ जुड़ते हैं।
• Attendance Save केवल बदली entries भेजता है। 80 में 1 बदला तो 1 entry;
  बिना बदलाव दोबारा Save करने पर कोई नया attendance request नहीं जाता।
  पुराने request IDs, authorization और expected-status conflict checks बने रहते हैं।
• Attendance/exam/Work Assign के पहचाने हुए read-only RPC अब मौजूदा bounded
  request scheduler में आते हैं। समान pending reads एक request साझा कर सकते हैं।
  Attendance/fee/access का completed response cache नहीं किया जाता।
• Work Assign: dropdown filters तुरंत लागू; create/edit/reassign/progress में
  failed Save पर form सुरक्षित, uncertain reply पर उसी request की Retry;
  account बदलने पर पुराने जवाब नए account की screen नहीं बदलते।
• Read-only assigned-work loading Back/Home को अनावश्यक नहीं रोकती।
• Backup का PostgreSQL 57014 statement-timeout definite failure माना जाता है;
  UI pending Save में हमेशा बंद नहीं रहती, कोई automatic retry नहीं होती।
  Scheduler status fail होने पर भी उपलब्ध backup list दिखाई देती है।
• SQL07 scalar fields पर अनावश्यक recursive redaction calls घटाता है। वही
  tables, पुराने fee records, secret-field filtering और function grants सुरक्षित हैं।
